# AquaGuard AI Prototype

AquaGuard AI is a frontend research prototype for water-safety monitoring. It presents a dashboard for:

- drowning-risk monitoring
- movement and posture analysis
- vulnerable-person monitoring
- wild-animal threat alerts
- public-area cleanliness monitoring

The app is built with `React`, `Vite`, `Tailwind CSS`, `React Router`, and `Recharts`.

## Project Structure

Key folders:

- `src/` - application pages, layout, UI components, and mock data
- `public/videos/` - local sample videos used by the monitoring cards
- `dist/` - production build output generated by `npm run build`

## Requirements

Install these on another laptop before running the project:

- `Node.js` 18 or newer
- `npm` 9 or newer
- `git`

To verify installation:

```powershell
node -v
npm -v
git --version
```

## How To Set Up On Another Laptop

1. Clone the repository:

```powershell
git clone https://github.com/teamcore38-droid/AquaGuard-AI-prototype.git
cd AquaGuard-AI-prototype
```

2. Install dependencies:

```powershell
npm install
```

3. Start the development server:

```powershell
npm run dev
```

4. Open the local URL shown in the terminal.

Vite usually starts on:

```text
http://localhost:5173/
```

- `public/videos/normal bathing video.mp4`
- `public/videos/drowning detection cam01.mp4`

## If The Project Does Not Start

Try these checks:

1. Make sure `node_modules` exists. If not, run:

```powershell
npm install
```

2. Make sure Node.js is installed:

```powershell
node -v
```

3. If dependencies look broken, delete `node_modules` and reinstall:

```powershell
Remove-Item -Recurse -Force node_modules
npm install
```

4. If port `5173` is already in use, Vite may automatically choose another port. Use the exact URL shown in the terminal.

## Notes

- `node_modules/` should not be pushed to GitHub.
- `dist/` is generated output and should not be edited manually.
- The app currently uses mock data from `src/data/mockData.js`.
- Authentication is local-only and meant for demonstration, not production use.
